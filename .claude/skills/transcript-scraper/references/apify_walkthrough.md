# Apify walkthrough (give to the user one step at a time)

Two Apify tools ("actors"), one per platform:
- **YouTube:** **YouTube Transcript Scraper** by devsef, https://apify.com/devsef/youtube-transcript-scraper
- **TikTok:** **TikTok Transcript Scraper** by mu0i, https://apify.com/mu0i/tiktok-transcripts (see the TikTok section below)

## YouTube facts (checked October 2026; re-check the actor page if anything looks different)

- **Input:**
  - `videoUrls`: up to **200 per run**
  - `language`: default `en`
  - `includeSegments`: timestamped segments, default on
  - `proxyConfiguration`: default Apify Residential
- **Output per video:**
  - `videoId`, `url`, `title`, `status`, `language`, `isAutoGenerated`, `segmentCount`, `charCount`, `text`, `error`
  - `segments`: a list of `{start, duration, text}`, in seconds
- **Status values:**
  - `ok`: the only status that's charged
  - `no_transcript`: the video has no captions, so retrying won't help
  - `unavailable`: the video is private, deleted or region-locked
  - `blocked`: retry it
  - `error`: retry it
- **Price:** $0.002 per successful transcript, plus Apify's own compute and residential-proxy usage. Measured in practice:

  | Run size | Cost |
  |---|---|
  | 3 videos | $0.015 |
  | 24 videos | ~$0.085 |
  | 182–200 videos | ~$0.60–0.64 |

  So budget **about $0.003–$0.005 per video**.
- **Free plan:** a monthly platform credit, about $5 at the time of writing. The sidebar shows "Usage $X / $5.00".
- **Speed:** about 200 videos in 15–20 minutes.
- **Occasional failure:** a few videos per few hundred come back as `error` with "Timedtext request threw: fetch failed". These succeed on a retry.

## Steps for the user

### 1. Make a free account
Go to https://apify.com and click **Sign up**. Signing in with Google or with email is fine. The free plan doesn't need a card. If anything asks for payment details, stop and tell me. The free plan should be enough.

### 2. Open the actor
Go to **https://apify.com/devsef/youtube-transcript-scraper** and click **Try for free**. You'll land on its **Input** page in your account.

### 3. Test run with 3 links
1. In **YouTube videos**, remove any example link using the red ✕.
2. Click **Bulk edit** and paste the first 3 lines of `links_part1.txt`. Click **Set**.
3. **Preferred language:** `en`, unless the show is in another language.
4. **Include timestamped segments:** make sure the switch is green. The 2-minute timestamp markers depend on it.
5. **Proxy configuration:** leave it on **Residential**.
6. *(Optional)* Under **Run options**, set **Maximum cost per run** to a safety cap. For 200 videos, $3 is plenty.
7. Click **Save & start**. It takes about a minute.
8. In **Output**, every row should show `ok` in the Status column and `en` in Language, with segment counts in the hundreds or thousands for hour-long episodes.

### 4. Export the test
1. Click **Export**, top right.
2. View: **All fields**. Format: **JSON**. Click **Download**.
3. The file lands in Downloads as `dataset_youtube-transcript-scraper_<date>.json`. Move it into the show folder's `apify_exports/`, or tell Claude and it will move it.
4. If Apify shows a pop-up asking to share your runs with the developer, **Dismiss** is fine. It isn't needed.

Claude then runs the converter on the test file and checks that the 3 transcripts look right before you spend more.

### 5. Full runs
Repeat steps 3–4 for each `links_partN.txt` file, with all of its links at once (up to 200). On a Mac, Claude can put the links on your clipboard, so you only need to click **Bulk edit**, select all, paste and click **Set**.

### 6. Retries
If the converter reports failures worth retrying, run one more small job with the links in `retry_links.txt`. It's usually just a few videos, costing a cent or two. Export it into `apify_exports/` as before.

## TikTok (mu0i TikTok Transcript Scraper)

### Facts (checked October 2026)
- **What it reads:** TikTok's own caption track. It doesn't do AI transcription, so posts without captions come back with `hasTranscript: false` and are free.
- **Input:**
  - `videoUrls`, and/or `profiles` (an @handle or profile URL)
  - `maxVideosPerProfile`: default 20; shown as **Videos per creator** in the form
  - `languages`
  - `includeSegments`
- **Output per post:**
  - `videoId`, `url`, `authorUsername`, `description` (the post caption), `createdAt`, `durationMs`
  - `hasTranscript`, `text`, `segments` (`{start, end, text}` with HH:MM:SS.mmm times), `wordCount`, `note`
  - **No view counts.** If the user wants to filter by views, you'd need a separate TikTok post-listing actor first (for example Clockworks TikTok Scraper), then pass the chosen video URLs to this one.
- **Price:** $4 per 1,000 transcripts on the free plan, so $0.004 each, and nothing for posts without captions. Measured: 213 posts, 210 with captions, cost $0.84.
- **Coverage:** in testing, profile mode returned a creator's whole catalogue (213 posts going back about 19 months) when the limit was set to 400.
  - **Not filtered by date:** the run doesn't stop at a date. Every post it returns is charged, even ones you'll throw away.
  - **Set the limit to fit:** set **Videos per creator** to roughly the creator's posting rate times the period, plus a margin.
- **Quirks:**
  - Occasionally a row has `createdAt` or `authorUsername` missing. `convert_tiktok.py` reads the date from the video ID and fills the handle from `--handle`.
  - TikTok video IDs carry the post time: `id >> 32` is Unix seconds. That's handy for checking dates in the Apify table, which doesn't show `createdAt`.

### Steps for the user
1. Open https://apify.com/mu0i/tiktok-transcripts and click **Try for free**.
2. Under **TikTok video URLs**, remove the example link with the red ✕.
3. Open **By creator instead of by URL**. Click **+ Add**, type the handle (`@creatorhandle`), and set **Videos per creator**. Use 3 for a test; for a full run, choose a number big enough to reach the date cutoff.
4. Under **Output**, leave **Include timestamped segments** on.
5. Open **Run options** and set **Maximum cost per run** to the agreed cap, for example `2`.
6. Click **Save & start**. When it finishes, the status line reads like "N rows, M transcripts charged, K without captions (free)".
7. Click **Export**. In the dialog, choose **All fields** and **JSON**, then click **Download**. Move the file into `apify_exports/`.

## If Claude is driving the browser for the user

- **Finding the actor's input page:**
  - First time: open the actor's Store page and click **Try for free**.
  - After that: it's under **Actors → Runs**, or at `console.apify.com/actors/<id>/input`.
  - Store-style console URLs like `console.apify.com/actors/user~name` may 404; use the Store page instead.
- **Fill the links in directly instead of pasting from the clipboard.** In testing, the user copied something else while waiting, and a paste would have put the wrong link in. Instead:
  1. Click **Bulk edit**.
  2. Set the textarea's value from the link file's contents, using the native value setter so the page notices the change: `Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype,'value').set.call(ta, links)`, then dispatch an `input` event.
  3. Check that the dialog's "N items" label and the number of valid `youtube.com/watch?v=` lines both equal the expected count, with no trailing blank line.
  4. Only then click **Set**.
  5. Afterwards, confirm the number of URL fields on the form matches.
- **Pasting instead:** if you do paste, a trailing newline makes the count one too high (for example, "201 items"). Delete the last empty line before clicking **Set**.
- **Export dialog:** the **Transcripts | All fields** switch exists both on the page and inside the dialog, so make sure you're clicking the one in the dialog. "Transcripts" leaves out the segments, which breaks the timestamp markers. After downloading, check that the JSON rows have a `segments` field.
- **Confirm with the user before Save & start.** Tell them the number of videos and the estimated cost.
- **Poll the run without hammering the page.** About every 5–10 minutes, read the status line ("Running", or "Succeeded … N results") and the Output count.
- **Confirm with the user before Export → Download.** Find the newest `dataset_youtube-transcript-scraper_*.json` in Downloads and move it into `apify_exports/`.
- **Never type the user's password or payment details.** Never accept terms on their behalf.
